## The self-keyed seam (what the paper never declares)
The paper's "ground truth" is constructed by intervening on the model: a
component's contribution is the model-output difference between the original
and the intervened input (Eq.1). The GT is therefore the model's OWN response
to perturbation — the same input-sensitivity address that the top-scoring
attribution methods compute.

The top-scoring tabular methods are the backprop family (Gradient, near-perfect
SIM 0.980 / KL 0.092), which compute the SAME local input-sensitivity the GT
reads (the analytic gradient IS the first-order perturbation response). The
falsifier (score the method against the GT) reads its witness from the same
address as the channel that produced the claim (the method's attribution) ->
the acceptance test is itself self-keyed. A mis-record at the
input-sensitivity level (the gradient the GT is built from is wrong) slips
through both the claim and the falsifier. The genuinely independent witness is
a cross-channel read (a different model, a held-out dataset, an independent
attribution, or a known causal structure), not a second read of the same
model's perturbation response.

## The fair counterweight (why the GT is not vacuous)
The perturbation methods (RISE/LIME) use a DIFFERENT read path (finite-difference
sampling, not the analytic gradient) and score lower (time-series RISE best,
SIM 0.522 / KL 0.790). So the GT does discriminate between families: backprop
(near-perfect on tabular) vs perturbation (much lower). The self-keyed seam is
specific to the backprop family, not the whole method set. This is the
discriminating cell: the GT is a valid cross-family comparator but a
self-keyed acceptance test for the backprop family.
