## The two-place test (the discriminating instrument)
For a paper whose claim C is supposed to be witnessed by check I:
  (a) is I executed at all? (does the call site exist / does the loop reach it?)
  (b) if executed, does I's output track the NAMED mechanism (not a different axis)?
A robust paper passes both. Each mode is its own falsifier; the modes do not imply each
other. This names the CAUSE of an "unwitnessed" gap (witness dead vs witness off-axis);
the existing unwitnessed-receipt / unwitnessed-root axes name the CONSEQUENCE. The
classification changes the correction: add the missing call site vs report the
actually-witnessed axis.

## Orthogonality (why the pair, not a restatement)
A live-but-off-axis check (CORE-RL) and a dead check (BFCL) do not imply each other.
CORE-RL shows the witness can be present and active yet miss the named mechanism; BFCL
shows the witness can be absent entirely. A single specimen cannot separate these; the
pair is the two-place case. Reuse: before asserting "claim unwitnessed," run the
two-place test to classify WHICH mode — the classification changes the correction, not
just the verdict.
